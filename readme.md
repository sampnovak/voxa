# VOXA ✦

### Words without boundaries.

VOXA is a creative playground for language, imagination, and discovery. It lets you invent fictional words, transform ordinary sentences into imaginary languages, explore real translations, create secure passwords, and journey through an immersive word game.

Whether you're experimenting with sounds, making up your own vocabulary, or simply playing with language, VOXA gives you a place to explore.

---

## ✨ Features

### 🔮 Word Laboratory
- Generate completely fictional words.
- Explore different language-inspired phonetic styles.
- Choose between natural, soft, sharp, ancient, futuristic, and dreamy sounds.
- Customize word length and the number of generated words.
- Copy your generated vocabulary.

### 🌀 Sentence Shifter
- Transform ordinary sentences into fictional language.
- Keep repeated words consistent within a transformation.
- Copy or listen to your transformed sentences.

### 🌍 Real Translator
- Translate actual text between supported languages.
- Switch between source and target languages.
- Uses the MyMemory translation API.

### 🔐 Secure Password Lab
- Generate readable, memorable passphrases.
- Create random character-based passwords.
- Generate pronounceable passwords.
- Customize password length and character options.
- Uses the browser's cryptographically secure random number generator.
- Password generation happens locally in your browser.

### 🎮 VOXA Realms
- Explore five fictional realms.
- Solve invented-word challenges.
- Earn XP and build streaks.
- Unlock achievements.
- Test your intuition and imagination.

---

## 🚀 Getting Started

VOXA is designed to be simple to run.

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start exploring!

No build tools, package managers, or installation process are required.

```bash
git clone https://github.com/YOUR-USERNAME/voxa.git
cd voxa
```

Then open `index.html`.

## 🌌 The Idea Behind VOXA

Language is more than communication. It is also sound, rhythm, creativity, and imagination.

VOXA explores the idea of creating words that feel like they belong to a real language, even when they have no intended meaning.

It is a small universe for people who enjoy experimenting, inventing, discovering, and playing with words.

**Make words. Break words. Discover new worlds.**
